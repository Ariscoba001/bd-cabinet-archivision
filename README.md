# Base de données relationnelle — Cabinet ArchiVision

Projet académique · Module Base de Données · Cycle ISE 2 · ENEAM-RESA/UAC

## Contexte

Étude de cas pour un cabinet d'architectes fictif (ArchiVision) confronté à des problèmes de gestion : informations clients dispersées, absence de vision globale sur l'avancement des projets multi-phases, et suivi manuel de l'affectation des employés.

## Contenu du dépôt

```
Documents_Projets/
  Document_Analyse_Conception.pdf   # Analyse métier + modélisation MCD/MLD
  MLD & MCD.pdf                     # Schémas de modélisation conceptuelle et logique
  Manuel_Utilisation.pdf            # Guide d'utilisation du système
Jeux_de_donnees/
  CLIENT.csv
  EMPLOYE.csv
  PROJET.csv
  PHASE.csv
  PHASE_PROJET.csv
  AFFECTATION.csv
Projet_HOUNKPATIN.accdb             # Base de données Microsoft Access
```

## Démarche

1. **Analyse de la problématique métier** : centralisation des données clients, suivi des projets par phase (Esquisse, APS, APD, PRO, DCE...), gestion des affectations d'employés.
2. **Modélisation conceptuelle et logique des données** (MCD/MLD).
3. **Implémentation** d'un système de gestion relationnel sous Microsoft Access, avec 6 tables liées.
4. **Documentation** : manuel d'utilisation destiné aux futurs utilisateurs du système.

Microsoft Access · Modélisation MCD/MLD · SQL
